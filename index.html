Unit 4 — Final Assignment

Agente do desafio final do Hugging Face Agents Course, construído com @theokit/sdk em TypeScript.

Resultado: 55% no GAIA nível 1 — 11 de 20, contra uma nota de corte de 30%.

TypeScript @theokit/sdk OpenRouter GAIA nível 1 MIT

Responde às 20 questões de nível 1 do GAIA servidas pela API de avaliação do curso e submete o resultado para pontuação. O gate do certificado é 30% — 6 de 20 respostas corretas.

O código completo está na aba Files deste Space.

Como funciona

Cada questão roda num agente próprio e descartável, com um conjunto fixo de ferramentas. Contexto de uma questão nunca contamina a seguinte.

FerramentaPara que serve
web_searchDescobre quais páginas ler (DuckDuckGo, sem API key)
fetch_pageLê uma página como texto, preservando tabelas em formato pipe
read_task_fileDecodifica anexos de texto e código; planilhas xlsx viram CSV
describe_imageResponde perguntas sobre imagens anexadas
transcribe_audioResponde perguntas sobre áudio anexado
youtube_transcriptLegendas com marcação de tempo, para o que é dito num vídeo
run_pythonAritmética, contagem e execução do código anexado, com timeout rígido

Formato da resposta

A pontuação é por igualdade exata de string, então o formato pesa tanto quanto a pesquisa. O agente termina com FINAL ANSWER: <x>; o módulo src/lib/answer.ts extrai o valor e remove o marcador, que o curso proíbe no texto submetido.

Onde o agente executa

Este Space usa o SDK static: publica o código e esta página. O agente executa localmente, porque Spaces com SDK Docker — necessários para rodar Node.js — exigem plano pago na conta que hospeda o projeto.

O Dockerfile e o servidor web (src/server.ts) estão versionados e funcionais. Numa conta com Docker liberado, trocar sdk: static por sdk: docker mais app_port: 7860 no cabeçalho do README faz o agente rodar dentro do próprio Space, sem outra alteração.

Rodando

git clone https://huggingface.co/spaces/paulohenriquevn/hf-agents-course-unit4-final
cd hf-agents-course-unit4-final
npm install

echo "OPENROUTER_API_KEY=sk-or-v1-..." > .env

npm test        # testes da lógica pura, sem rede
npm run eval    # responde as 20 questões, grava answers.json
npm run submit  # submete o answers.json já gerado

eval e submit são passos separados de propósito: cada submissão aparece no leaderboard público do curso.

Construído com

TheoKit SDK — SDK TypeScript e runtime de agentes, com 43 provedores de LLM nas suas próprias chaves, MCP, subagentes, workflows e sandbox de execução.

Site: theokit.dev · Código: github.com/usetheokit/theokit-sdk

Deste SDK o projeto usa Agent.create com ferramentas próprias, Tool.create com schemas Zod, PermissionPlugin para negar ferramentas, Retry.create com jitter e Budget como teto de gasto.
